Switch quota discovery to CLIProxyAPI's Management API instead of reading local auth files. Add `/cliproxy-usage setup` (alias `login`) and `/cliproxy-usage logout` to enter and validate a masked Management API password, stored as `managementKey`, in a bordered/titled prompt matching `/cliproxy-usage settings` and with working paste support. Add a `managementUrl` override setting for management endpoints that differ from the provider base URL. Add DeepSeek balance support, discovered through `/v0/management/openai-compatibility`. Show the CLIProxyAPI web dashboard URL (`<root>/management.html`) in setup, settings, and status. Refreshes now scope to the active model's matching provider and cache results across model switches. The retired local auth path setting (`accountsDir`) is dropped on save; Management API account selection is available in manual mode, and email masking remains available. Fix silent background refreshes (session start, `/new`, `/reload`, model switches, the periodic timer) repeatedly popping a "Management password not configured" toast; that warning now only shows for an explicit `/cliproxy-usage` or `/cliproxy-usage refresh`.
